# Dataset

This project retrieves the Iranian Churn Dataset directly from the UCI Machine Learning Repository with `ucimlrepo` dataset ID 563.

Source: https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset  
DOI: https://doi.org/10.24432/C5JW3Z  
License: CC BY 4.0

The raw file is not duplicated here. This keeps source attribution clear and makes the data-acquisition step reproducible.
